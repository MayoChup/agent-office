Kebijakan Privasi

Kantor AI Rico · Privacy Policy · Terakhir diperbarui 11 November 2026

Kantor AI Rico adalah aplikasi pribadi milik Rico Andriawan, dipakai hanya oleh pemiliknya sendiri. Aplikasi ini tidak tersedia untuk umum.

Kantor AI Rico is a personal application used only by its owner, Rico Andriawan. It is not offered to the public.

Data yang diakses / Data accessed

Dengan izin pemilik melalui Google OAuth, aplikasi dapat mengakses Gmail, Google Calendar, Google Drive, Google Docs, Google Sheets, dan Kontak milik pemilik. Contohnya: membaca email notifikasi transaksi bank untuk dicatat ke Google Sheets milik pemilik, dan membaca jadwal kalender.

With the owner's consent via Google OAuth, the app accesses the owner's Gmail, Calendar, Drive, Docs, Sheets and Contacts — for example, reading bank transaction notification emails to record them in the owner's own Google Sheet.

Penggunaan data / How data is used

  • Data hanya dipakai untuk membantu pemilik (pencatatan keuangan, jadwal, dokumen).
  • Data tidak dijual, tidak dibagikan kepada pihak ketiga, dan tidak dipakai untuk iklan.
  • Email tidak dikirim, dihapus, atau diubah tanpa persetujuan pemilik.
  • Token akses disimpan di server pribadi pemilik dan dapat dicabut kapan saja di myaccount.google.com/permissions.

Data is used only to assist the owner. It is never sold, shared with third parties, or used for advertising. Access tokens are stored on the owner's private server and can be revoked at any time.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
